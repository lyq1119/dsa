# 数据结构与算法学习记录

这里收录我在 2026 年春季学期学习数据结构与算法时完成的题解、课程作业与复习资料。主要使用 Python，少量题目使用 C++。

## 目录说明

| 目录 / 文件 | 内容 |
| --- | --- |
| `lt/` | LeetCode 题解，文件名通常以题号和题目名称命名。 |
| `lg/` | 洛谷（Luogu）题解，覆盖图论、动态规划、树形 DP、差分约束等。 |
| `oj/` | 课程 Online Judge 题解。 |
| `cf/` | Codeforces 练习题解。 |
| `sw/` | 算法练习与专题代码。 |
| `homework/` | 课程作业、实验及相关材料。 |
| `cheatsheet/` | 考试/复习速查表，包含 Markdown、PDF 与截图版本。 |
| `好题整理.md` | 值得复习的题目与笔记。 |
| `OOP.py` | Python 面向对象编程练习。 |

## 使用方式

题解大多是独立程序或在线评测平台的提交代码：

```bash
# 运行标准输入/输出形式的题解
python3 "lg/P2515 软件安装.py" < input.txt
```

LeetCode 文件通常只包含平台要求的 `Solution` 类，需要在 LeetCode 编辑器中运行，或自行补充题目提供的类型定义与测试代码。

## 约定

- 代码按来源平台分别存放，文件名保留题号和原题名称，便于检索。
- 不同题目的输入输出格式以题目原文为准。
- 这是个人学习仓库；部分早期代码可能保留当时的命名、注释和提交形式。
